# سامانه ثبت آگهی خرید و فروش دست دوم

پروژه درس برنامه‌سازی پیشرفته — معماری کلاینت/سرور با Backend اسپرینگ‌بوت و کلاینت JavaFX.

این مخزن شامل **فاز ۱ (پایه مشترک)** و **فاز ۲ (سرور + کلاینت)** به‌صورت کد کامل و قابل‌اجراست.
فازهای ۳ (یکپارچه‌سازی و تست مسیرها) و ۴ (امتیازی و تحویل) در `DESIGN.md` تعریف شده‌اند.

\## 👥 سازندگان و اعضای تیم

این پروژه توسط تیم دو نفره ما توسعه یافته است:

\- \*\*زهرا احمدی:\*\* توسعه‌دهنده بخش \*\*Backend\*\* (طراحی دیتابیس، معماری اسپرینگ‌بوت، امنیت JWT و REST APIs)

\- \*\*کیمیا فاتحی:\*\* توسعه‌دهنده بخش \*\*Frontend\*\* (طراحی رابط کاربری JavaFX، مدیریت FXMLها و یکپارچه‌سازی ارتباطات شبکه)

## پشته فناوری

* **Backend:** Java 17، Spring Boot 3.3، Spring Data JPA، Spring Security + JWT، H2 فایل‌محور، Bean Validation
* **Frontend:** JavaFX 21 + FXML، `java.net.http.HttpClient` + Jackson (ارتباط REST)
* **Build:** دو پروژه Maven مجزا (`backend/`، `frontend/`)

## پیش‌نیازها

* JDK 17
* Maven 3.9+

## اجرا

### ۱) اجرای Backend

```bash
cd backend
mvn spring-boot:run
```

سرور روی `http://localhost:8080` بالا می‌آید. بار اول داده نمونه ساخته می‌شود (کاربران، دسته‌ها، شهرها، چند آگهی).
کنسول دیتابیس: `http://localhost:8080/h2-console` — JDBC URL: `jdbc:h2:file:./data/marketplace` (کاربر `sa`، بدون رمز).

### ۲) اجرای Frontend (در ترمینال دوم)

```bash
cd frontend
mvn javafx:run
```

## قابلیت‌های پیاده‌سازی‌شده (فاز ۱ و ۲)

* **احراز هویت:** ثبت‌نام، ورود، توکن JWT، اعتبارسنجی یکتایی نام کاربری/موبایل، رمز hashشده (BCrypt).
* **آگهی (CRUD):** ثبت، ویرایش (مالک)، حذف نرم، علامت فروخته‌شده؛ سه نوع با **ارث‌بری/چندریختی** (خودرو/املاک/عمومی).
* **جست‌وجو و فیلتر ترکیبی:** متن، نوع، دسته، شهر، بازه قیمت، مرتب‌سازی (جدیدترین/قیمت/امتیاز)، صفحه‌بندی — با `JpaSpecificationExecutor`.
* **بررسی ادمین:** صف آگهی‌های در انتظار، تأیید/رد؛ آمار؛ مسدود/فعال‌سازی کاربر.
* **علاقه‌مندی، چت خریدار–فروشنده (با وضعیت دیده‌شدن)، امتیازدهی ۱–۵** با قواعد یکتایی و مالکیت.
* **امنیت لایه‌ای:** کنترل نقش/مالکیت در Backend؛ کلاینت فقط از لایه `api/` درخواست می‌زند.
* **هندلر سراسری خطا:** همه خطاها با ساختار JSON یکسان و کد HTTP درست؛ نمایش خطا در کلاینت با `Alert`.

## ساختار پروژه

```
backend/
  src/main/java/com/ap/marketplace/
    domain/           موجودیت‌ها + enumها (ارث‌بری Advertisement)
    repository/       Spring Data JPA
    dto/              درخواست/پاسخ (records)
    service/          منطق دامنه + AdSpecifications
    controller/       REST endpointها
    security/         JWT، فیلتر، پیکربندی امنیت
    exception/        خطاها + GlobalExceptionHandler
    config/           DataSeeder
frontend/
  src/main/java/com/ap/marketplace/client/
    SceneManager, Session
    api/              ApiClient + کلاس‌های API + DTOها
    controller/       کنترلرهای صفحه‌ها
  src/main/resources/fxml/   صفحه‌های FXML
API\_CONTRACT.md       قرارداد کامل API (خروجی فاز ۱)
DESIGN.md             سند طراحی و نگاشت به جدول نمره‌دهی
```

## گام بعدی (فاز ۳ و ۴)

* فاز ۳: تست دستی همه مسیرها (ثبت‌نام/ورود، ثبت آگهی، بررسی ادمین، جست‌وجو/فیلتر، علاقه‌مندی، چت، امتیاز).
* فاز ۴: قابلیت‌های امتیازی باقی‌مانده، تست‌های JUnit بیشتر، افزودن اسکرین‌شات‌ها و سهم اعضای گروه.
